# T5a Orchestration Sample

このファイルは、親エージェント責務確認 T5a のためのテスト用 fixture である。

正本文書ではない。
このファイルの目的は、親エージェントが直接実装せず、実装サブエージェントへ渡す暫定実装タスクを整理できるかを確認することである。

## 実装サブエージェント

### 出力

実装サブエージェントは以下を返す。

- 実施内容
- 変更ファイル
- 実行したテスト
- テスト結果
- 監査結果
- blocking の有無
- 自動再修正を実行した場合の回数と理由
- non-blocking / out-of-scope がある場合は、自動修正しなかった理由

## Codex / 親エージェント

### 出力

親エージェントは最終結果を返す。
